# DevWorkspace paylaşım metinleri

## Kısa tanım

Windows desktop workbench for discovering projects, reviewing Git changes, inspecting dependency vulnerabilities, and launching development tools across stacks.

## Türkçe paylaşım

Bir .NET çözümü, birkaç React uygulaması, bir Flutter projesi… Proje sayısı arttıkça hangi repoda ne kaldığını takip etmek zorlaşıyor.

Bu ihtiyaç için DevWorkspace'i geliştiriyorum: projelerini klasörlerinden keşfeden, Git durumlarını ve paket güvenliği bulgularını tek Windows ekranında bir araya getiren bir masaüstü uygulaması.

• Farklı teknoloji yığınlarında proje keşfi
• Git diff, geçmiş, branch ve worktree araçları
• NuGet ve desteklenen JavaScript/Dart paketleri için güvenlik taramaları
• Favoriler, filtreler ve çalışma profilleri

Arayüz şu an Türkçe; uygulama .NET 10 ve WPF ile geliştiriliyor. Kaynaktan derlemek için DevExpress WPF paketlerine erişim gerekiyor.

Senin geliştirme klasöründe nasıl çalıştığını merak ediyorum. Denersen tanınmayan proje türlerini ve günlük akışında eksik kalan işlemleri issue olarak paylaşabilir misin?

https://github.com/developersenturk/DevWorkspace

## English introduction

I’m building DevWorkspace, a Windows desktop workbench for developers juggling projects across different stacks.

Point it at a development folder to discover projects, review Git changes, inspect dependency vulnerabilities, and launch your tools from one workspace. It also includes favorites, saved filters, launch profiles, and GitHub Actions and Docker Compose integrations.

Built with .NET 10 and WPF. The interface is currently in Turkish, and building from source requires access to the DevExpress WPF dependencies.

I’d love feedback from people working across several repositories: which project types does it miss, and which daily workflow would you want it to simplify?

https://github.com/developersenturk/DevWorkspace
