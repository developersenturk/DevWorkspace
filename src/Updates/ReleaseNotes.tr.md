## Gömülü web arayüzlerinin proje altında gösterilmesi

- .NET projelerinin Node.js betikleriyle derlediği ClientApp arayüzleri artık bağımsız uygulama olarak listelenmez; ana projenin Bileşenler bölümünde gösterilir.
- Ana projeye bağlı gömülü web arayüzlerinin ayrı proje satırları oluşturması önlenerek proje listesindeki yinelenen kayıtlar giderildi.
