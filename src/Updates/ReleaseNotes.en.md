## Quick access to Git changes

- Uncommitted changes (diff) in a project's context menu opens the Git view with the first change's side-by-side diff. Staged, modified and new files can be reviewed from the same view.

## Development hub and updates

- The Development hub brings workspace checks, launch profiles and daily development tools together in one entry point.
- Pending updates for the same or an older version than the running application are no longer applied.

## Work and maintenance

- Open Work and maintenance from File or the Development hub to access five new daily development tools.
- Work sets save related projects, branches or detached commits, project notes and a launch profile together. Resume checks repositories, switches branches safely and opens the projects. Starting services is optional.
- Error solutions suggest inspection or remediation steps for known port, SDK, dependency, environment and service connection errors. Commands are shown before execution. Inspect port owners by process name and PID.
- Change impact identifies directly and transitively affected projects and related tests through local .NET and JavaScript dependencies. Run the displayed test commands sequentially; .NET tests use Debug.
- Environment variants create setups such as Local, Docker or Frontend only from an existing profile. Values from a selected local environment file apply only to the relevant process, preserving the existing .env file and system settings. Team configuration shares file paths, never file contents.
- Resources and cleanup shows RAM/CPU usage for managed commands and their child processes. Preview known outputs and caches by file and size, then recycle or explicitly confirm permanent cleanup. Tracked Git files, running projects, links and changed/incomplete scans are protected.
