## Release notes inside the app

- Use **What's new** in the top bar to read what changed in each version.
- Notes for your current version are available without an internet connection.
- Recent stable GitHub releases appear in the same window. Select a version to see its changes.
- Previously loaded notes remain available when you are offline.

## From the previous version

- Release Center packages .NET Framework executables together with their dependencies.
- Apps without Velopack integration can be distributed as portable ZIPs. Installer lifecycle and automatic updates require startup integration in the target app.
